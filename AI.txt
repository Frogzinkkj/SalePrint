1. Stack Tecnológica Base
Backend: Java (21) com Spring Boot

Dependências: Spring Web, Spring Data JPA, PostgreSQL Driver, Spring Validation, Lombok, OpenCSV (para a importação inicial da planilha).

Frontend: Angular (versão 17+ usando Standalone Components para facilitar o aprendizado e reduzir o boilerplate).

Bibliotecas: Angular Material ou Tailwind CSS (para estilização rápida do dashboard e tabelas).

Banco de Dados & Infra: PostgreSQL rodando em um container Docker, orquestrado com um docker-compose.yml que também subirá a aplicação posteriormente.

2. Modelagem do Banco de Dados (Entidades JPA)
Esta é a estrutura exata que o Spring Data JPA vai transformar em tabelas:

Localidade

id (Long, PK, Auto-increment)

nome (String, Unique) -> Ex: Inicializar com "Dom Bosco" e "Camaçari".

Setor

id (Long, PK, Auto-increment)

nome (String) -> Ex: "Tesouraria", "Secretaria", "RH".

localidade (ManyToOne -> Localidade)

Impressora

id (Long, PK, Auto-increment)

marca (String)

modelo (String)

numeroSerie (String, Unique)

ip (String, Unique)

status (Enum) -> ATIVA, BACKUP, PROVISORIA, COM_DEFEITO_INTERNO, EM_MANUTENCAO_QUALYCOPY, RETIRADA.

setor (ManyToOne -> Setor)

observacao (String)

Movimentacao (A tabela de log inalterável)

id (Long, PK, Auto-increment)

impressora (ManyToOne -> Impressora)

dataMovimentacao (LocalDateTime)

setorOrigem (ManyToOne -> Setor, nullable)

setorDestino (ManyToOne -> Setor)

statusAplicado (Enum do Status)

responsavel (String) -> Ex: "Marcel", "Mércio", "TI", "Qualycopy".

osQualycopy (String, nullable) -> Número do chamado externo.

descricao (String)

3. Regras de Negócio e Serviços (Backend Spring Boot)
gere os seguintes Services principais:

ImpressoraService:

Deve validar se o IP inserido já existe em outra impressora com status ATIVA.

Sempre que o método updateImpressora for chamado e detectar mudança de setor ou status, ele não deve apenas atualizar a tabela, mas obrigatoriamente chamar o MovimentacaoService para registrar a linha do tempo.

MovimentacaoService:

Garante que o registro de movimentação seja salvo com a data/hora do servidor.

GlpiIntegrationService:

Um serviço usando WebClient ou RestTemplate. Quando uma impressora mudar o status para COM_DEFEITO_INTERNO, este serviço dispara um POST para a API do GLPI abrindo um chamado de infraestrutura, incluindo no corpo da mensagem o IP, S/N, Marca/Modelo e o Setor atual da impressora.

ImportacaoCsvService:

Um script de inicialização (@PostConstruct ou um endpoint isolado) para ler aquele arquivo .csv que você tem, fazer a limpeza dos espaços em branco nas Strings e popular o banco de dados inicial, migrando tudo de uma vez.

4. Escopo do Frontend (Angular)

Componentes Principais (/src/app/components):

dashboard.component: A tela inicial com cards (Total Ativas, Total Manutenção Qualycopy, Total Backups disponíveis).

impressora-list.component: Uma tabela com paginação e filtro de busca por IP ou S/N. Cada linha tem um botão de "Ver Histórico" e "Movimentar".

impressora-form.component: O formulário para cadastrar um equipamento novo do zero.

movimentacao-modal.component: Um modal (caixa sobreposta) que abre quando você clica em "Movimentar". Ele já traz a impressora bloqueada na tela e pede apenas: Novo Status, Novo Setor, Responsável e OS (se for o caso da Qualycopy).

timeline.component: Uma visualização vertical mostrando o histórico de uma impressora específica.

rie um docker-compose.yml apenas com o PostgreSQL (porta 5432) e o pgAdmin

configure o application.properties para conectar no Postgres do Docker.

🚀 COMO USAR AGORA:

1. Subir banco de dados:
   docker-compose up -d

2. Compilar e executar (pasta backend/):
   cd backend
   .\mvnw.cmd clean package
   java -jar target\impressora-1.0.0.jar

3. Frontend:
   cd frontend
   ng serve

4. Testar API:
   - Swagger UI: http://localhost:8080/api/swagger-ui.html
   - pgAdmin: http://localhost:5050

5. App web: http://localhost:4200

6. Exemplo de primeiro acesso:
   - GET /api/localidades (para listar localidades iniciais)
   - POST /api/impressoras (cadastrar primeira impressora)
   - GET /api/movimentacoes/historico/1 (ver histórico)
